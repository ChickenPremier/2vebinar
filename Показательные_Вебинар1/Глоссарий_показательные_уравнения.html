1. Свойства степени

Основные свойства степеней (для a > 0, b > 0)
  • aⁿ · aᵐ = aⁿ⁺ᵐ — произведение степеней
  • aⁿ : aᵐ = aⁿ⁻ᵐ — частное степеней
  • (aⁿ)ᵐ = aⁿ·ᵐ — степень степени
  • (a·b)ⁿ = aⁿ·bⁿ — степень произведения
  • (a/b)ⁿ = aⁿ/bⁿ — степень частного
  • a⁰ = 1 — нулевая степень (при a ≠ 0)
  • a⁻ⁿ = 1/aⁿ — отрицательная степень
Степень с рациональным показателем

a^(m/n) = ⁿ√(aᵐ) — при a ≥ 0

a^(-m/n) = 1 / (a^(m/n))

Пример 1

Упростите: 4³ · 4⁻²

Решение: 4³ · 4⁻² = 4³⁻² = 4¹ = 4

Ответ: 4

2. Показательная функция

Показательная функция

Функция вида y = aˣ, где a > 0, a ≠ 1, называется показательной.

Область определения: D(y) = R (все действительные числа)

Область значений: E(y) = (0; +∞) — функция всегда положительна

Свойства показательной функции y = aˣ
  • Если a > 1 — функция возрастает на R
  • Если 0 < a < 1 — функция убывает на R
  • График всегда проходит через точку (0; 1)
  • График не пересекает ось Ox (стремится к нулю, но не достигает)
Пример 2

Сравните: 2,1⁵ и 2,1⁷

Решение: Основание 2,1 > 1, значит функция y = 2,1ˣ возрастающая. Чем больше показатель, тем больше значение.

Ответ: 2,1⁵ < 2,1⁷

3. Показательные уравнения

Метод приведения к общему основанию
a^(f(x)) = a^(g(x)) ⇔ f(x) = g(x) (при a > 0, a ≠ 1 — показатели можно «убрать»)
Метод 1. Приведение к одному основанию

Обе части уравнения приводим к степени с одним и тем же основанием, затем приравниваем показатели.

Пример 3

Решите уравнение: 2ˣ = 16

Шаг 1. Представим 16 как степень с основанием 2: 16 = 2⁴

Шаг 2. Получили: 2ˣ = 2⁴ → основание одно → x = 4

Ответ: 4

Метод 2. Метод замены переменной

Если уравнение содержит выражения вида aˣ и a²ˣ (или a⁻ˣ), вводим замену t = aˣ. Получаем уравнение относительно t (чаще всего квадратное), затем возвращаемся к замене и решаем aˣ = t₁.

Важно: для показательной функции всегда выполняется t > 0. Отрицательные корни отбрасываем.

Пример 4

Решите уравнение: 9ˣ − 4·3ˣ + 3 = 0

Шаг 1. Заметим, что 9ˣ = (3²)ˣ = 3²ˣ = (3ˣ)²

Шаг 2. Замена t = 3ˣ > 0: t² − 4t + 3 = 0 → t₁ = 1, t₂ = 3

Шаг 3. 3ˣ = 1 → x = 0; 3ˣ = 3 → x = 1

Ответ: 0; 1

Метод 3. Вынесение общего множителя

Если уравнение содержит одинаковые степени с разными показателями (например aˣ и aˣ⁺¹), выносим наименьшую из них за скобку.

Пример 5

Решите уравнение: 2ˣ⁺¹ + 2ˣ = 24

Шаг 1. Выносим 2ˣ за скобку: 2ˣ(2 + 1) = 24

Шаг 2. 3·2ˣ = 24 → 2ˣ = 8 → 2ˣ = 2³

Шаг 3. x = 3

Ответ: 3

4. Показательные неравенства

Неравенство a > 1 (возрастающая) 0 < a < 1 (убывающая)
a^(f(x)) > a^(g(x)) f(x) > g(x) f(x) < g(x) ⚠
a^(f(x)) ≥ a^(g(x)) f(x) ≥ g(x) f(x) ≤ g(x) ⚠
a^(f(x)) < a^(g(x)) f(x) < g(x) f(x) > g(x) ⚠
Главное правило

При a > 1 знак неравенства сохраняется

При 0 < a < 1 — знак неравенства меняется на противоположный 🚨

Пример 6 (основание a > 1)

Решите неравенство: 2ˣ > 16

Шаг 1. 16 = 2⁴ → 2ˣ > 2⁴

Шаг 2. Основание 2 > 1, знак сохраняем: x > 4

Ответ: (4; +∞)

Пример 7 (основание 0 < a < 1) ⚠

Решите неравенство: (1/2)ˣ < 8

Шаг 1. Приведём к одинаковому основанию: (1/2)ˣ = 2⁻ˣ и 8 = 2³

Шаг 2. 2⁻ˣ < 2³ → основание 2 > 1 → −x < 3 → x > −3

Ответ: (−3; +∞)

Пример 8 (основание 0 < a < 1, ловушка) ⚠

Решите неравенство: (0,5)ˣ > 0,25

Шаг 1. 0,25 = (0,5)² → (0,5)ˣ > (0,5)²

Шаг 2. Основание 0,5 < 1 → функция убывает → знак меняем: x < 2

Ответ: (−∞; 2)

5. Сведение неравенств к методу интервалов

Разделение на случаи

Неравенство вида a^(f(x)) > b, где b не является степенью числа a, решаем через логарифм:

Для a > 1: x > log_a b

Для 0 < a < 1: x < log_a b

Метод введения новой переменной в неравенствах

Замена t = aˣ > 0. Решаем неравенство относительно t, затем учитываем ОДЗ t > 0.

Пример 9

Решите неравенство: 4ˣ − 5·2ˣ + 4 ≤ 0

Шаг 1. 4ˣ = (2ˣ)². Замена t = 2ˣ > 0

Шаг 2. t² − 5t + 4 ≤ 0 → корни t₁ = 1, t₂ = 4

Шаг 3. Метод интервалов: 1 ≤ t ≤ 4 → 1 ≤ 2ˣ ≤ 4

Шаг 4. 2⁰ ≤ 2ˣ ≤ 2² → 0 ≤ x ≤ 2

Ответ: [0; 2]

6. Задания ЕГЭ — разбор типовых задач

Задание №7 (профиль) — простейшее уравнение

Здесь требуется решить несложное показательное уравнение. Обычно — приведение к одному основанию.

2ˣ⁺⁵ = 0,25

0,25 = 1/4 = 2⁻² → 2ˣ⁺⁵ = 2⁻² → x + 5 = −2 → x = −7

Задание №13 (профиль) — уравнение с отбором корней

Показательное уравнение сводится к квадратному методом замены. Затем — тригонометрия или логарифмы на отбор корней.

Пример 10 (типовое задание №13)

Решите уравнение: 3^(2x+1) + 10·3ˣ + 3 = 0

Шаг 1. 3^(2x+1) = 3·3²ˣ = 3·(3ˣ)². Замена t = 3ˣ > 0

Шаг 2. 3t² + 10t + 3 = 0 → D = 100 − 36 = 64 → t₁ = −3, t₂ = −1/3

Шаг 3. Оба корня отрицательны, но t > 0 — значит, корней нет

Ответ: нет решений
