Единичная окружность и тригонометрические функции
10 класс, профильный уровень

1. Основные определения

Единичная окружность

Окружность радиуса R = 1 с центром в начале координат O(0; 0).

Уравнение: x² + y² = 1

Тригонометрические функции на единичной окружности

Пусть P(x; y) — точка на единичной окружности, соответствующая углу α.

Определения:

  • cos α = x (абсцисса точки P)
  • sin α = y (ордината точки P)
  • tg α = y/x (при x ≠ 0)
  • ctg α = x/y (при y ≠ 0)
Пример 1

Для угла 90° точка P имеет координаты (0; 1).

Следовательно: cos 90° = 0, sin 90° = 1, tg 90° не определён, ctg 90° = 0.

2. Основное тригонометрическое тождество

Основное тождество
sin²α + cos²α = 1
Пример 2

Найдите sin²120° + cos²120°.

Решение: По основному тождеству sin²α + cos²α = 1 для любого α.

Ответ: 1

4. Знаки тригонометрических функций по четвертям

I четверть (0°—90°)

Все функции положительны

sin α > 0, cos α > 0
tg α > 0, ctg α > 0

II четверть (90°—180°)

Только sin положителен

sin α > 0, cos α < 0
tg α < 0, ctg α < 0

III четверть (180°—270°)

Только tg и ctg положительны

sin α < 0, cos α < 0
tg α > 0, ctg α > 0

IV четверть (270°—360°)

Только cos положителен

sin α < 0, cos α > 0
tg α < 0, ctg α < 0

Мнемоническое правило

Все Студенты Трекают Классно

I четверть — Все (все положительны)
II четверть — Студенты (только sin)
III четверть — Трекают (только tg и ctg)
IV четверть — Классно (только cos)

Пример 4

Определите знак cos 135°.

Решение: 135° находится во II четверти (90° < 135° < 180°). Во II четверти cos α < 0.

Ответ: cos 135° < 0

5. Формулы приведения

Для углов вида 90° ± α:

Формулы для 90° ± α

sin(90° + α) = cos α     cos(90° + α) = -sin α

sin(90° - α) = cos α     cos(90° - α) = sin α

Для углов вида 180° ± α:

Формулы для 180° ± α

sin(180° + α) = -sin α     cos(180° + α) = -cos α

sin(180° - α) = sin α     cos(180° - α) = -cos α

Для углов вида 360° ± α:

Формулы для 360° ± α

sin(360° + α) = sin α     cos(360° + α) = cos α

sin(360° - α) = -sin α     cos(360° - α) = cos α

Пример 5

Найдите sin 210°.

Решение: 210° = 180° + 30°. Используем формулу: sin(180° + α) = -sin α.

sin 210° = sin(180° + 30°) = -sin 30° = -1/2

Ответ: -1/2

Пример 6

Найдите cos 135°.

Решение: 135° = 90° + 45°. Используем формулу: cos(90° + α) = -sin α.

cos 135° = cos(90° + 45°) = -sin 45° = -√2/2

Ответ: -√2/2

6. Связь между функциями

Связь tg и ctg с sin и cos

tg α = sin αcos α     ctg α = cos αsin α

Связь tg и ctg

tg α · ctg α = 1

Пример 7

Найдите tg 225° · ctg 225°.

Решение: По формуле связи: tg α · ctg α = 1 для любого α.

tg 225° · ctg 225° = 1

Ответ: 1
