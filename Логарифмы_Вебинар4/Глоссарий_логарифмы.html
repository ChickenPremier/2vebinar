1Определение логарифма

Логарифм — это показатель степени, в которую нужно возвести основание, чтобы получить число.

loga b = c ⟺ ac = b, где a > 0, a ≠ 1, b > 0

Читается: «логарифм числа b по основанию a». Основание a — то, что возводим; b — то, что получаем.

Пример: log2 8 = 3, потому что 23 = 8. Вопрос «в какую степень возвести 2, чтобы получить 8?» — ответ 3.

2ОДЗ логарифма

Логарифм существует только при строгих условиях на основание и подлогарифмическое выражение:

основание: a > 0 и a ≠ 1  ·  число: b > 0
  • Основание положительно и не равно 1 (единица в любой степени даёт 1 — логарифм бессмыслен).
  • Под логарифмом — только строго положительное число: log ноля и отрицательных чисел не существует.
Пример: log3(x − 2) существует при x − 2 > 0, то есть x > 2. А запись log−2 8 или log1 5 — запрещена.

3Простейшие значения

Пять значений, которые надо знать наизусть — они встречаются в каждом варианте ЕГЭ:

log2 8 = 3  ·  log3 1 = 0  ·  log5 5 = 1  ·  lg 100 = 2  ·  ln e = 1
  • loga 1 = 0 при любом a — нулевая степень даёт 1 (поэтому log3 1 = 0).
  • loga a = 1 — первая степень даёт само основание (поэтому log5 5 = 1).
  • lg — десятичный логарифм (основание 10): lg 100 = 2, так как 102 = 100.
  • ln — натуральный логарифм (основание e ≈ 2,7): ln e = 1.
Пример: log2 8 = 3, потому что 23 = 8; lg 100 = 2; ln e = 1.

4Основное логарифмическое тождество

Степень и логарифм с одинаковым основанием «съедают» друг друга:

aloga b = b (при a > 0, a ≠ 1, b > 0)
Пример: 2log2 7 = 7; 5log5 12 = 12. Тождество превращает «этаж» в обычное число.

5Сумма логарифмов → произведение

Сумма логарифмов с одинаковым основанием сворачивается в логарифм произведения:

loga M + loga N = loga(M·N)
Пример из вебинара: log3 1,8 + log3 5 = log3(1,8·5) = log3 9 = 2.

6Разность логарифмов → частное

Разность логарифмов с одинаковым основанием сворачивается в логарифм частного:

loga M − loga N = loga(M / N)
Пример из вебинара: log5 60 − log5 12 = log5(60 / 12) = log5 5 = 1.

7Степень внутри и в основании

Показатель подлогарифмического выражения выносится множителем, а показатель основания — обратным числом:

loga Mk = k·loga M   ·   logak M = (1/k)·loga M
Пример: log2 83 = 3·log2 8 = 3·3 = 9; log8 4 = log23 22 = (2/3)·log2 2 = 2/3.
⚠️ Формула loga Mk = k·loga M при чётном k требует M > 0. Нельзя писать log x2 = 2·log x без оговорки: при x < 0 левая часть существует, а правая — нет. Корректно: log x2 = 2·log|x|.

8Переход к новому основанию и следствия

Любой логарифм можно выразить через логарифмы с удобным основанием c:

loga b = logc b / logc a

Два полезных следствия:

loga b = 1 / logb a   ·   loga b · logb c = loga c
Пример: log8 16 = ln 16 / ln 8 = (4·ln 2) / (3·ln 2) = 4/3. А цепочка log2 3 · log3 5 = log2 5 — среднее звено «сократилось».

9Логарифмическая функция y = loga x

  • Область определения: D: x > 0 (график живёт только справа от оси Oy).
  • Множество значений: E: все y (любое число достижимо).
  • Общая точка: всегда проходит через (1; 0), ведь loga 1 = 0.
  • При a > 1 — возрастает; при 0 < a < 1 — убывает.
a > 1: растёт ↗  ·  0 < a < 1: убывает ↘  ·  точка (1; 0)
Пример: y = log2 x растёт и проходит через (1; 0), (2; 1), (8; 3). А y = log1/2 x убывает: чем больше x, тем меньше y.

10Показательная функция y = ax — пара логарифма

Показательная и логарифмическая функции взаимно обратны — их графики симметричны относительно прямой y = x:

y = ax: D — все x, E: y > 0, точка (0; 1)
  • D: все x; E: только y > 0 (степень положительного числа всегда положительна).
  • Всегда проходит через (0; 1), ведь a0 = 1.
  • При a > 1 растёт, при 0 < a < 1 убывает — как и логарифм с тем же основанием.
Пример: y = 2x проходит через (0; 1), (3; 8); а y = log2 x — её зеркальное отражение: точки (1; 0), (8; 3).

11Приём с клетками: две целые точки дают a и b

На ЕГЭ график логарифма y = loga(x + b) или y = ax + b узнают по клеткам: берут две точки с целыми координатами и подставляют в уравнение.

  • Шаг 1. Найди на графике две точки с целыми координатами (например, (1; 0) и (4; 1)).
  • Шаг 2. Подставь их в формулу — получишь систему из двух уравнений на a и b.
  • Шаг 3. Реши систему: обычно одна точка сразу даёт b, вторая — основание a.
Пример: график проходит через (1; 0) и (4; 1): 0 = loga(1 + b), 1 = loga(4 + b). Из первого: 1 + b = 1 ⇒ b = 0; из второго: a1 = 4 ⇒ a = 4.

12ОДЗ-ловушки

  • Нельзя опускать логарифмы без проверки: из loga f(x) = loga g(x) следует f(x) = g(x) только при условии f(x) > 0 и g(x) > 0. Найденные корни обязательно подставляй в ОДЗ — посторонние отбрасывай.
  • Основание-буква требует проверки ≠ 1: если в основании параметр или выражение с x, отдельно проверь a > 0 и a ≠ 1 для каждого кандидата.
  • Сумма логарифмов уже, чем логарифм произведения: log f + log g требует f > 0 и g > 0, а log(f·g) — только f·g > 0. При «схлопывании» область может расшириться — проверяй исходное ОДЗ.
⚠️ Главная ошибка вебинара: решить log3(x − 1) = log3(5 − x), получить x = 3 и забыть проверку. Здесь повезло: 3 − 1 = 2 > 0 и 5 − 3 = 2 > 0 — корень подходит. Но соседний пример с нулём или минусом под логарифмом дал бы посторонний корень!
